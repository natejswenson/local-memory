# Full coach connection outside a repository

A global memory-only registration exposes owned notes but cannot answer current
fitness questions. Configure the optional full `fitness` stdio server under the
same key used by the project to avoid duplicate aliases. Preserve unrelated MCP
settings and save original configuration privately before an authorized change.

The installer must support upgrading its own restricted registration and refuse to
overwrite an unrelated pre-existing server. Verify the tool list and coach/brief
prompts in a fresh client; check current data only within the user's authorized
scope. Keep live measurements, session identifiers, and detailed verification
receipts in private runtime storage. Do not infer personal readiness from this
generic integration plan.
